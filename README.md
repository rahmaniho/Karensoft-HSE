# کارن HSE

داشبورد نمایشی سامانه مدیریت ایمنی، بهداشت و محیط زیست کارن سافت؛ پیاده‌سازی‌شده با React و Vite، کاملاً فارسی و راست‌چین.

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

## ساخت و استقرار

```bash
npm run build
```

پروژه برای استقرار مستقیم روی Vercel آماده است؛ Vercel به‌صورت خودکار Vite را تشخیص می‌دهد. مسیر خروجی ساخت `dist` است.

## محدوده نسخه فعلی

این نسخه یک MVP رابط کاربری است. صفحه‌های رخدادها، بازرسی، اقدامات اصلاحی، ارزیابی ریسک، پروژه‌ها، کارکنان و آموزش، گزارش‌ها، تنظیمات و پشتیبانی دارای ایجاد/ویرایش/جستجو/فیلتر وضعیت/تغییر گردش وضعیت/حذف محلی هستند. برای هر مورد مسئول، اولویت، مهلت و شرح تکمیلی نگهداری می‌شود. اطلاعات در `localStorage` ذخیره می‌شود. هر بخش از CSV و نسخه پشتیبان JSON پشتیبانی می‌کند و نسخه JSON قابل بازیابی است. رخدادهای ثبت‌شده از داشبورد در فهرست رخدادها نیز همگام می‌شوند. پوسته PWA و service worker برای بازکردن دوباره برنامه در حالت آفلاین افزوده شده است.

این ذخیره‌سازی صرفاً روی مرورگر و دستگاه فعلی است: بین کاربران/دستگاه‌ها همگام نمی‌شود، پاک‌کردن داده‌های مرورگر اطلاعات را حذف می‌کند و رمزنگاری یا کنترل دسترسی فراهم نمی‌کند. برای داده عملیاتی حساس، اطلاعات پزشکی یا استفاده چندکاربره مناسب نیست. بخش‌هایی مثل موتور گردش‌کار، RBAC واقعی، API و پایگاه داده چندمستأجری فعلاً پیاده‌سازی نشده‌اند. داده‌های اولیه داشبورد نمونه هستند. طرح فنی و مسیر تکمیل در `docs/architecture.md` آمده است.
